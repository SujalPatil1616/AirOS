# AirOS Roadmap

1. **Foundation:** install a pinned Python environment; verify package imports and unit tests.
2. **Camera preview:** detect a hand and draw MediaPipe landmarks.
3. **Gesture stability:** smooth finger-count estimates and add a visible enable/disable state.
4. **Safe desktop controls:** add opt-in pointer movement only after tracking is stable; require an explicit clutch gesture and emergency quit.
5. **Portfolio polish:** add tests, screenshots, architecture notes, and a short demo video.

No mouse or keyboard actions are enabled in this starter.
